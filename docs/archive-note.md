# Archive Note

The private project originally contained detailed Japanese v2 and v3 operational
history: incident logs, routine checks, migration notes, and runbooks. Those
documents are valuable internally, but they are too environment-specific for a
public repository.

The public snapshot keeps English contracts, procedures, decision records and
sanitized dated evidence. The [catalog](00_INDEX.md) distinguishes their roles;
the [status archive](status-history-2026-11-03.md) preserves older checkpoints.
Source code, tests, manifests and monitoring configuration establish the design.
Claims about an operated result additionally identify their observation window
and evidence limits.
